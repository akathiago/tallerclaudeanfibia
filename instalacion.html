Instalación

Todo lo que hace falta antes del taller, en orden. Lo opcional está al final.

¿Por qué instalar todo esto?

Para correr Claude Code te alcanza la app de escritorio. Git, GitHub y Node no están acá para que la herramienta funcione: están para que pueda trabajar sobre tus archivos de verdad, y para que vos puedas volver atrás cuando se equivoque.

Git es el ejemplo claro. Un agente actúa, mira el resultado y vuelve a intentar: es rápido justamente porque puede equivocarse. Git es el punto de guardado que te deja dejarlo trabajar tranquilo, y GitHub es lo que después convierte eso en una dirección que podés compartir.

Claude Desktop + plan Pro

La app de escritorio donde vive Claude Code. El plan Pro cuesta USD 20 por mes y cubre Chat, Cowork y Code. Todo el taller se hace desde acá: la misma app abre tu carpeta, muestra los cambios y trae navegador y terminal.

  1. Entrá a claude.ai/download y descargá la app para tu sistema (Windows o Mac).
  2. Instalala y abrila. Iniciá sesión con tu cuenta, o creá una si no tenés.
  3. Andá a Configuración → Suscripción y activá el plan Pro.
  4. Entrá a la pestaña Code y elegí una carpeta de prueba para trabajar.

Verificar: escribile Hola, ¿en qué carpeta estás? Si te contesta con la ruta, ya está. Todos los "verificar" que siguen se hacen acá.

Git

El sistema de control de versiones. Hace falta para que Claude Code pueda guardar el historial de cambios de tu proyecto.

Windows

  1. Descargalo de git-scm.com/download/win
  2. Instalalo dejando todas las opciones por defecto.

Mac

  1. La mayoría de las Mac ya lo traen. Pedile a Claude que se fije y, si falta, que te guíe.

Verificar: ¿Tengo Git instalado? ¿Qué versión?

GitHub

No es un programa que se instale: es la cuenta donde tu código queda guardado y compartible.

  1. Creá una cuenta gratis en github.com.
  2. (Opcional pero recomendado) Pedile a Claude: Configurá Git con mi nombre y mi mail, y pasale los dos datos.

Node.js

El entorno que le permite a Claude Code correr scripts y levantar servidores locales fuera del navegador.

  1. Descargá el instalador LTS de nodejs.org (Windows o Mac).
  2. Instalalo con las opciones por defecto.
  3. Cerrá la app de Claude y abrila de nuevo, para que encuentre el programa nuevo.

Verificar: ¿Tengo Node instalado? ¿Qué versión?

Opcionales

Con lo de arriba ya estás

Esto no hace falta para el taller. Sumalo solo si lo necesitás o si te da curiosidad.

Opcional

VS Code

Un editor de código completo, para quien quiera ver y tocar los archivos con más detalle. La app de Claude ya muestra archivos y cambios, así que no hace falta.

  1. Descargalo de code.visualstudio.com
  2. Instalalo y abrilo.
  3. En la barra de íconos de la izquierda, entrá a Extensiones (el ícono de los cuatro cuadraditos, o Ctrl + Shift + X en Windows / Cmd + Shift + X en Mac).
  4. Buscá Claude Code y apretá Install en la de Anthropic.

Verificar: reiniciá VS Code y fijate que aparezca el ícono de Claude en la barra lateral.

Opcional

Claude in Chrome

Una extensión que le da a Claude acceso a tu navegador real, con tus cuentas abiertas. Sirve cuando tiene que entrar a un sitio donde ya iniciaste sesión. Para probar tu propio sitio no hace falta: la app trae un navegador adentro (Ctrl + Shift + B en Windows, Cmd + Shift + B en Mac).

  1. Usá Chrome, Edge, Brave, Arc, Vivaldi u Opera. En Firefox y Safari no funciona: ahí quedate con el navegador de la app.
  2. Instalá la extensión desde la Chrome Web Store.
  3. Iniciá sesión en la extensión con la misma cuenta que usás en la app.

Ojo: entra con tu sesión, así que puede leer y tocar lo que vos podés. Mirá qué permiso te pide y no la dejes sola en sitios sensibles.

Opcional

La terminal

No se instala y no hace falta abrirla: Claude corre los comandos por vos. Si querés mirar, la app trae una adentro: botón Terminal arriba, o Ctrl + `. Se abre en la carpeta de tu sesión.

Opcional · Solo Mac

Homebrew

Un atajo para quien ya se maneja en la terminal: instala programas con una sola línea. No es obligatorio, y en Windows no hace falta.

  1. Entrá a brew.sh y copiá el comando que aparece ahí.
  2. Pegalo en la terminal y apretá Enter. Puede pedir la contraseña de tu Mac.

Verificar: brew --version

Opcional

Python

Solo si tu trabajo implica manejar datos: planillas, bases, análisis, gráficos. No es requisito para el resto del taller.

  1. Descargalo de python.org/downloads (Windows o Mac).
  2. En Windows, durante la instalación, marcá la casilla "Add Python to PATH".

Verificar: ¿Tengo Python instalado? ¿Qué versión?
