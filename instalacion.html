Instalación

Todo lo que hace falta instalar antes del taller, en orden.

¿Por qué instalar todo esto?

Para correr Claude Code te alcanza la app de escritorio. Todo lo demás no está acá para que la herramienta funcione: está para que pueda trabajar sobre tus archivos de verdad, y para que vos puedas volver atrás cuando se equivoque.

Git es el ejemplo claro. Un agente actúa, mira el resultado y vuelve a intentar: es rápido justamente porque puede equivocarse. Git es el punto de guardado que te deja dejarlo trabajar tranquilo, y GitHub es lo que después convierte eso en una dirección que podés compartir.

Imprescindible

Claude Desktop + plan Pro

La app de escritorio donde vive Claude Code. El plan Pro cuesta USD 20 por mes y cubre Chat, Cowork y Code.

  1. Entrá a claude.ai/download y descargá la app para tu sistema (Mac o Windows).
  2. Instalala y abrila. Iniciá sesión con tu cuenta, o creá una si no tenés.
  3. Andá a Configuración → Suscripción y activá el plan Pro.
Solo Mac

Homebrew

El instalador de línea de comandos de Mac. Resuelve versiones y dependencias por vos: con Homebrew instalado, todo lo que sigue se instala con una sola línea. En Windows no hace falta, se saltea este paso.

  1. Entrá a brew.sh (ahí está el mismo comando, por si cambia).
  2. Abrí la Terminal (Cmd + Espacio, escribí "terminal").
  3. Pegá esta línea y apretá Enter:
    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
  4. Seguí las instrucciones en pantalla. Puede pedir la contraseña de tu Mac.

Verificar: brew --version

Git

El sistema de control de versiones. Hace falta para que Claude Code pueda guardar el historial de cambios de tu proyecto.

Mac

  1. Con Homebrew instalado: brew install git

Windows

  1. Descargalo de git-scm.com/download/win
  2. Instalalo dejando todas las opciones por defecto.

Verificar: git --version

GitHub

No es un programa que se instale: es la cuenta donde tu código queda guardado y compartible.

  1. Creá una cuenta gratis en github.com.
  2. (Opcional pero recomendado) Configurá Git con tu identidad:
    git config --global user.name "Tu nombre"
    git config --global user.email "tu@mail.com"

Node.js

El entorno que le permite a Claude Code correr scripts y levantar servidores locales fuera del navegador.

Mac

  1. brew install node

Windows

  1. Descargá el instalador LTS de nodejs.org
  2. Instalalo con las opciones por defecto.

Verificar: node --version

VS Code

El editor donde vas a ver tus archivos, tu código y la terminal en un mismo lugar.

  1. Descargalo de code.visualstudio.com
Opcional

Python

Solo si tu trabajo implica manejar datos — planillas, bases, análisis, gráficos. No es requisito para el resto del taller.

Mac

  1. brew install python

Windows

  1. Descargalo de python.org/downloads
  2. Durante la instalación, marcá la casilla "Add Python to PATH".

Verificar: python3 --version (Mac) / python --version (Windows)
