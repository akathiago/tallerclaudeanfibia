Lecturas

Textos para pensar esto con más calma.

  • Más allá del chat: cómo los modelos de lenguaje potencian el conocimiento académico — Mauro Santelli (421.news) ¿Y si la IA no viene a reemplazarte, sino a ser el asistente de investigación que nunca pudiste pagar? Cómo usar herramientas como Claude Code, Zotero y Obsidian para automatizar lo tedioso y potenciar la argumentación académica profunda.
  • Claude Code: el fin del software como lo conocemos — Juan Ruocco (421.news) Una mirada sobre cómo Claude Code cambia los moats del software y el lugar de quien programa.
  • The Making of Claude Code — Anthropic La historia de cómo se construyó la herramienta, contada por quienes la hicieron.
  • ¿Sin programadores? No hay problema: periodistas crean sus propias aplicaciones de IA — LatAm Journalism Review Redacciones de Argentina y Uruguay (ADNSUR, Búsqueda) que se armaron sus propias herramientas sin tener a nadie que programe. Lo más cerca de casa que hay.
  • Cómo uso Claude Code sin ser ingeniero — José Ignacio Flores (Fintualist) Un periodista chileno cuenta cómo hizo weatherchile.app y cómo trabaja con el agente: el método, no solo el resultado. Está en la página de Proyectos.
  • Antes hacía documentos de Word. Ahora hago apps hasta para lo más tonto — Ricardo Aguilar (Xataka) Herramientas chiquitas para el trabajo de todos los días, hechas por alguien que no programa. La mejor respuesta a "¿y yo para qué lo usaría?".
  • Claude Code for writers — Casey Newton (Platformer, en inglés) Consejos e ideas para quien escribe, de un periodista que se hizo su web con Claude Code y no paró más.
  • I vibe coded a complex data visualisation and analysis dashboard. Here's what I learned — Jaemark Tordecilla (Reuters Institute, en inglés) Un periodista sin formación técnica arma un tablero de datos entero y cuenta qué salió bien, qué no y cómo chequeó que los números fueran correctos.
  • I Used Claude to Build a Personalized CRM (Then I Tried Using It) — Chris Scott (The Paperless Agent, en inglés) Construir algo es la mitad. Esta nota cuenta la otra: qué pasó cuando lo usó todos los días, y por qué lo terminó dejando.

Cursos y herramientas

Documentación, cursos y herramientas para seguir después del taller.

  • Claude Code for Everyone — Carl Vellotti Aprendé Claude Code adentro de Claude Code. Curso gratuito que enseña IA haciéndola: sin videos, sin documentación y sin experiencia previa en programación, solo trabajo real adentro de la herramienta. Muy bueno para practicar con un caso ficticio.
  • Documentación oficial de Claude Code La referencia técnica completa: comandos, configuración, todo lo que no entra en el taller.
  • Awesome Claude Code Lista curada de skills, hooks, comandos y herramientas de la comunidad, para cuando quieras ir más allá de lo básico.
  • NameThatUI Le mostrás un elemento de interfaz y te dice cómo se llama — para pedirle exactamente eso a tu agente, no "el cuadradito ese".
