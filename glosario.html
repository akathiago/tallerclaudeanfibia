Comandos y atajos Git(hub) Referencias Glosario

Glosario

Las palabras que van a aparecer en el taller, explicadas en una o dos líneas. Si falta alguna, preguntásela a Claude: "explicame qué es X como si no supiera nada de programación".

Agente
Un modelo al que le diste herramientas y permiso para usarlas: lee archivos, corre comandos, prueba lo que hizo y vuelve a intentar hasta terminar. Claude Code es un agente; el chat común no.
Alucinación
Cuando la IA inventa algo que suena verdadero y no lo es: un dato, una cita, una fuente. Por eso todo lo que importa se verifica.
API
La puerta por la que un programa le pide cosas a otro. Cuando una app "usa Claude" por dentro, le habla por su API.
API key
La llave que identifica quién paga cada pedido a una API. No se comparte ni se sube a GitHub: si se filtra, otro gasta con tu cuenta.
CLAUDE.md
Un archivo de instrucciones que Claude lee siempre al empezar. Hay uno global (sobre vos, para todos tus proyectos) y uno por proyecto (sobre ese proyecto).
Commit
Una foto de tu carpeta guardada con Git, con un mensaje que dice qué cambió. Es el punto al que podés volver si algo se rompe.
Contexto
Todo lo que el modelo tiene presente para responder: la conversación, las instrucciones, los archivos que leyó. Tiene un tamaño máximo: cuando se llena, se pone lento y olvida.
Deploy
Publicar: pasar tu proyecto de tu compu a internet, con una dirección que cualquiera puede abrir.
Diff
La lista de diferencias entre dos versiones de un archivo: qué líneas se agregaron y cuáles se borraron. Sirve para ver qué tocó Claude.
Git
El programa que guarda la historia de una carpeta en tu compu. Funciona sin internet y sin cuenta.
GitHub
Un sitio web donde se guarda una copia de lo que Git registró. Es como el Google Drive de los programadores.
HTML, CSS y JavaScript
Los tres archivos de una página web. HTML es qué hay (textos, fotos, links), CSS es cómo se ve y dónde va cada cosa, y JavaScript es qué pasa cuando alguien toca algo.
Localhost
Tu propia computadora funcionando como servidor. Cuando Claude te dice que tu sitio está en "localhost", anda, pero solo lo ves vos.
Markdown
Una forma de escribir texto con estructura usando símbolos simples: # para títulos, - para listas. Los archivos .md (como CLAUDE.md o SKILL.md) están escritos así.
MCP
El enchufe que conecta a Claude con otro programa (Notion, Drive, GitHub) para que pueda leer y escribir ahí sin que vos copies y pegues.
Modelo
El sistema que genera las respuestas: Haiku, Sonnet, Opus. La app es la interfaz; el modelo es el motor.
Modo plan
Un modo en el que Claude investiga y te propone qué va a hacer, pero no toca nada hasta que lo aprobás.
Node.js
El programa que permite correr JavaScript fuera del navegador. Claude lo usa para levantar tu proyecto y probarlo.
Plugin
Un paquete que se instala de una vez y trae skills, subagentes o conexiones que armó otra persona.
Prompt
Lo que le escribís a la IA: tu pedido, con su contexto.
Push y pull
Push manda a GitHub los commits nuevos de tu compu. Pull trae a tu compu lo nuevo que haya en GitHub.
Repositorio (repo)
Una carpeta con su historia de Git. "Subí el repo" quiere decir "subí la carpeta con todo su historial".
Sesión
Una conversación con Claude Code. Queda guardada en la barra lateral de la app y la podés retomar.
Skill
Un instructivo guardado en un archivo SKILL.md que le enseña a Claude a hacer una tarea de una manera puntual. Se usa con / y su nombre.
Subagente
Otra copia de Claude, con su propio contexto, a la que el agente principal le encarga una parte del trabajo. Vuelve solo con el resultado.
Terminal
Una ventana donde se le habla a la computadora escribiendo comandos en vez de hacer clic. Claude la usa por vos; no hace falta abrirla.
Token
El pedacito de texto con el que trabaja el modelo: más o menos una sílaba o una palabra corta. Los límites de uso y de contexto se miden en tokens.
Vercel
Un servicio que mira tu repositorio de GitHub y lo publica en internet cada vez que guardás un cambio.
Vibe coding
Construir software describiendo lo que querés en lenguaje común, sin escribir el código. La palabra la inventó Andrej Karpathy en 2025.
